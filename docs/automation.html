Voice Control, OBS Studio & Bot Automation Guide

Control OBS Studio scenes, sources, camera zoom, audio faders, chat replies, plugins, and variables completely offline via Whisper voice commands, chat triggers, stream alerts, timers, or hardware decks.

Architecture

1. Triggers → Execution Queues → Actions → Sub-Actions

Location: Settings → General • Bot Navigation Tab

TownCrier includes a complete, local-first Bot Automation Engine that runs alongside Text-to-Speech (or completely standalone with TTS unchecked if you only want hands-free OBS & stream automation):

  • Independent from Voice Subtitles: You can enable Voice Detection (Offline Speech Recognition / Whisper) purely to trigger Bot Actions and OBS controls by voice without turning on Voice Subtitles or broadcasting captions.
  • Reusable Actions: Every workflow you build lives in Bot → Actions & Sub-Actions as an ordered list of steps. Any voice phrase, chat !command, stream alert, OBS event, timer, plugin trigger, or PoundControl button can invoke the same Action.
  • Blocking & Concurrent Queues: Configure named execution queues in Bot → Queues & Variables. Assign camera animations or multi-step scenes to a sequential (blocking) queue so Zoom → Wait → Reset finishes cleanly before the next trigger fires, while lightweight alerts run concurrently.

Zero Cloud Latency or Subscriptions: Speech recognition (Silero VAD + whisper.cpp Vulkan), OBS WebSocket v5 control, SQLite variables, and Lua-free If/Else logic run 100% locally on your PC.

Hands-Free Whisper Control

2. Offline Voice Control, Wake Word & Phonetic Matching

Location: Settings → General → Voice Detection • Bot → Commands & Voice

Speak naturally into your microphone while gaming or creating content to switch OBS scenes, trigger zoom animations, mute inputs, advance playlists, or post chat messages without lifting your hands off the controller or mouse.

Step-by-Step Voice Control Setup

  1. Open Settings → General, check Enable Bot Automation Engine, and check Enable Voice Detection (Offline Speech Recognition / Whisper). (Leave Enable Voice Subtitles unchecked unless you also want transparent OBS captions.)
  2. In the Voice Detection card right below (or Bot → Commands & Voice), choose your microphone, download any quantized GGML Whisper model (Tiny ~31 MB, Base ~57 MB, Small ~181 MB, or Large-v3-Turbo ~547 MB), and pick your compute mode—use Integrated iGPU Only to run Vulkan GPU inference on an onboard AMD/Intel iGPU without touching your discrete gaming GPU's VRAM.
  3. Open Bot → Commands & Voice to configure your Wake Word, Voice Match Mode, Response Voice, and test phrases with the Live Transcript Tester.

Wake Word, Armed Window & Confirmation Chime

  • Comma-Separated Wake Word Aliases: Enter optional wake phrases (for example, hey crier, octothorpe, hey octo — 2–3+ syllables recognize most reliably) and click Save.
  • Two Ways to Trigger When Armed:
    • Same Utterance: Say “Hey Crier, zoom in” in one breath—TownCrier strips the wake word and executes zoom in immediately.
    • Two-Step Armed Window: Say “Hey Crier” alone → TownCrier plays a confirmation chime (toggleable) and opens the Armed Window for your configured duration → say “zoom in” before the window expires.
  • Per-Command Ignore Wake Word: Check this on individual urgent or unmistakable voice commands (such as emergency mic mute) so they fire anytime without needing the wake word first.

Voice Match Modes

Four voice command matching algorithms evaluated against Whisper transcripts
Match Mode How It Matches Best Used For
Contains Phrase Matches contiguous spoken words after normalizing case, punctuation, and contractions (e.g. don't → dont) Everyday commands embedded naturally inside full sentences
Phonetic / Sound-Alike Uses consonant/vowel phonetic keys, Levenshtein distance, and adjacent token merging to tolerate speech-to-text spelling drift (e.g. octo matching auto, otto, octa, okto) Proper nouns, gamer tags, custom wake words, and shorthand commands that Whisper may spell slightly differently
Exact Match Requires the entire normalized utterance (after any wake word) to match the configured phrase exactly Short commands you want to guard against accidental triggers mid-sentence
Regular Expression (Regex) Runs a case-insensitive Go regular expression across the transcript (prefix with (?i) automatically unless provided) Matching multiple alternate phrasings or synonyms in a single command entry

Live Transcript Tester & Configurable Response Voice

  • Live Transcript Tester (Bot → Commands & Voice): View real-time Whisper transcripts alongside decode latency, wake-word state (waiting, armed, armed_window, same_utterance), matched commands, and cooldown skip reasons. Type any sample phrase into the tester to dry-run or live-execute triggers immediately without speaking into your mic.
  • Response Voice Override: Pick a dedicated Response Voice and speed for voice-triggered confirmations. Any Speak Text-to-Speech (TTS) sub-action inside the triggered Action whose own Voice ID is left on Global automatically speaks in your configured Response Voice.
OBS WebSocket v5

3. Controlling OBS Studio & Live Discovery

Location: Bot → OBS Studio • Bot → Actions & Sub-Actions

TownCrier speaks directly to OBS Studio over local OBS WebSocket v5 (included built-in with OBS Studio 28+), auto-populating live dropdown pickers so you never have to memorize internal scene or source spellings.

Connecting OBS Studio

  1. In OBS Studio, open Tools → WebSocket Server Settings, check Enable WebSocket server (default port 4455), and copy or set your password.
  2. In TownCrier, open Bot → OBS Studio, enter Host (127.0.0.1), Port (4455), and Password (saved securely in your OS Keyring), check Auto-Reconnect, and click Connect / Save.
  3. When editing any Control OBS Studio sub-action, TownCrier dynamically fetches live Scenes, Sources per scene (plus smart (Current Scene) targeting), Source/Scene Filters, Audio/Text/Media/Browser Inputs, and Scene Transitions.

Reacting Back from OBS Events

Automation isn't one-way: in Bot → Triggers & Timers, add a trigger with Source set to OBS Studio Event (such as CurrentProgramSceneChanged, StreamStateChanged, RecordStateChanged, SceneItemEnableStateChanged, or InputMuteStateChanged). Every key inside OBS's event payload (like %sceneName%, %outputActive%, %inputName%, or %inputMuted%) is automatically injected into the Action's variables.

Examples

6. Practical Configuration Recipes

Recipe 1: Hands-Free Voice Camera Zoom & Auto-Reset

Speak “Hey Crier, zoom in” mid-game to punch in your facecam for 4 seconds—but only when OBS is currently on your Gaming scene:

  1. In Settings → General, enable Bot Automation Engine and Voice Detection; in Bot → OBS Studio, connect OBS WebSocket (port 4455).
  2. In Bot → Queues & Variables, ensure your camera action uses a sequential (blocking) queue so rapid triggers don't stack overlapping zooms.
  3. In Bot → Commands & Voice, set Wake Word to hey crier (or octothorpe, hey crier).
  4. Create an Action named Cam Dramatic Zoom in Bot → Actions & Sub-Actions with these ordered steps:
    • If / Else Condition: Left = %obs.scene%, Operator = Equals, Right = Gaming (picked directly from the live OBS dropdown), If True = Continue to Next Step, If False = Stop Action (Break).
    • Control OBS Studio: Operation = Zoom Source (Relative Step), Scene = (Current Scene), Source = Webcam, Zoom Factor = 1.35.
    • Play Sound File: Optional sting audio cue.
    • Wait / Delay: 4000 ms.
    • Control OBS Studio: Operation = Reset Source Transform, Scene = (Current Scene), Source = Webcam.
  5. Add a Voice Command in Bot → Commands & Voice with Phrase = zoom in, Match Mode = Phonetic / Sound-Alike, Action = Cam Dramatic Zoom, and test it live in the Live Transcript Tester!

OBS Studio Mode tip: When Studio Mode is enabled with OBS's default Duplicate Scene option checked, live transform/zoom updates affect the underlying scene and won't show on Program until you transition. Click the gear icon next to the OBS Transition controls and uncheck Duplicate Scene if you want zoom/transform actions to update Program immediately.

Recipe 2: Chat & Voice !deaths Counter Updating an OBS Text Source

Let moderators in chat (or you by voice) increment a live stream-session death counter displayed right on OBS:

  1. In Bot → Queues & Variables, declare Variable Name = deaths, Scope = Session (Current Stream), Kind = Whole Number (Int), Default = 0 (resets to 0 automatically every stream).
  2. Create an Action Add Death with:
    • Increment Variable: Scope = Session, Key = deaths, Delta = 1.
    • Control OBS Studio: Operation = Set Text Source, Input = DeathCounterText, Text = Deaths: %session.deaths%.
    • Speak Text-to-Speech (TTS): %pick(Ouch!,Another one bites the dust!,Total is now %session.deaths%!)%.
    • Send Chat Message: %user% logged death #%session.deaths%!
  3. Attach both a Chat Command (!death, Mod/Broadcaster, Consume TTS checked) and a Voice Command (log death) to Add Death.

Recipe 3: Automatic BRB Routine When Switching OBS Scenes

  1. Create an Action Enter BRB Mode that mutes your mic in OBS (Mute / Unmute / Toggle Input → Mute on Mic/Aux), pauses or resumes CrowdDJ via Run Plugin Action, and announces Be right back! in chat.
  2. In Bot → Triggers & Timers, add a trigger with Source = OBS Studio Event, Event = CurrentProgramSceneChanged, Target = Enter BRB Mode, and add an If / Else Condition checking %sceneName% Equals BRB (else Break) as step 1.
