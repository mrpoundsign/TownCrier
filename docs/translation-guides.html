Architecture

How TownCrier Translation Works

TownCrier detects foreign livestream chat messages in-process in under 0.1ms and translates them before speaking them aloud (with an optional 3-note ascending chime) and recording both the original and translated text in your Event Logs.

  • Zero-Cost Target Language Short-Circuit: Emote codes, URLs, @mentions, and universal stream slang (gg, pog, lul) are stripped before detection. Any message or sentence already in your target language short-circuits locally without sending a single network packet.
  • Sentence Splitting & Two-Tier Spam Cache: Incoming messages are split into individual sentences. Repeated greetings (e.g., ¡Hola amigos!), copypastas, and raid spam hit an in-memory L1 LRU cache (1,000 sentences) at 0ms and 0 API cost. Any sentence seen 2 or more times is automatically promoted to the persistent L2 Disk Cache (cache/translations.json, up to 5,000 sentences) across app restarts.
  • Cascading Priority Fallback & Round-Robin Load Balancing: Enable multiple providers and drag ≡ or click ▲/▼ to order them. In Priority mode, TownCrier uses your #1 provider and automatically cascades down the list if a node hits a rate limit. In Round-Robin mode, TownCrier distributes requests evenly across all healthy enabled nodes.
  • Exponential Backoff (Up to 1 Hour): Transient errors or HTTP 429 rate limits place that node into an escalating cooldown (15s → 30s → 1m → 2m → 5m → 15m → 30m → 1h), while hard quota exhaustion or invalid API keys immediately cool down that node for 1h. Hover over any node's status icon or badge in Settings to see the exact backoff reason.
Default #1 Node

1. MyMemory Translated API (Zero-Setup Free)

MyMemory (operated by Translated.net) is enabled by default at priority #1 so translation works out of the box with zero registration or API keys.

Free Quotas & 10x Email Upgrade

  • Anonymous Mode (Default): 5,000 characters/day (~100 foreign chat messages/day) completely free with all fields left blank.
  • 10x Free Email Mode (Recommended): Click Configure on the MyMemory row in Settings → Translation and enter a valid email address in the Email (10x Free Quota) field to immediately unlock 50,000 characters/day (~1,000 foreign chat messages/day) with no signup, password, or credit card.

Privacy Note: Translated S.r.l. is an EU/GDPR-compliant company. The optional de email parameter is used strictly as an abuse-prevention contact header and is never sold to third-party marketers. Note that anonymous/free MyMemory translations contribute to their public translation memory archive—do not send private credentials through chat.

500,000 Free Chars / Mo

2. Google Cloud Translation API (Basic v2)

Google Cloud provides 500,000 characters/month FREE (~10,000 chat messages/month). Because Google's documentation can be confusing, follow the exact 4-step console walkthrough below.

Why Basic (v2) instead of Advanced (v3)? In Google's documentation sidebar, API v2 is called "Basic" and API v3 is called "Advanced". Advanced (v3) requires complex IAM Service Account JSON keyfiles and OAuth2 token exchanges, whereas Basic (v2) accepts a standard API key string and shares the exact same 500,000 free characters/month tier.

4-Step Setup in Google Cloud Console

  1. Create or Select a Google Cloud Project: Open Google Cloud Project Create, name your project (e.g., TownCrier), and click Create (or use your existing default project).
  2. Enable the Cloud Translation API: Open the Cloud Translation API Library page and click Enable. (Google requires linking a billing account to enable Cloud APIs, but you can hard-cap usage to $0.00 in Step 4).
  3. Create & Restrict Your API Key: Open APIs & Services → Credentials, click + Create credentials → API key, and copy the AIza... key into TownCrier's Google Cloud API Key field.
    Recommended Security Practice: Click your newly created key in the Credentials list, scroll to API restrictions, select Restrict key, check Cloud Translation API, and click Save.
  4. Guarantee $0.00 Overages (Set a Daily Quota Cap): Open IAM & Admin → Quotas, filter by Cloud Translation API, select v2 and v3 general model characters per day, click Edit Quotas, and set the daily limit to 15,000 characters/day (15,000 × 31 = 465,000 chars/month, safely below the 500,000 free monthly tier). If a stream ever hits 15,000 characters in a single day, Google returns HTTP 429 and TownCrier automatically cascades to your next provider without charging you a cent.
500,000 Free Chars / Mo

3. DeepL API (Free / Pro)

DeepL API Free provides 500,000 characters/month FREE (~10,000 chat messages/month) with industry-leading translation naturalness and a hard $0.00 cap (DeepL Free accounts never charge overages automatically).

Setup Steps

  1. Sign up for a free developer account at deepl.com/pro-api.
  2. Open your DeepL Account → API Keys tab and copy your key (Free keys end with :fx).
  3. In TownCrier, click Configure on the DeepL API row, paste the key into API Key (OS Keyring), check the box to enable the node, and click Done.
Self-Hosted / Open Source

4. LibreTranslate (Self-Hosted Docker or Managed API)

LibreTranslate is an open-source machine translation server powered by Argos Translate that you can run 100% locally on your own machine or LAN with unlimited free translations.

Run Locally via Docker (Unlimited & Free)

docker run -ti --rm -p 5000:5000 libretranslate/libretranslate

Leave the Server Endpoint URL in TownCrier set to http://localhost:5000 (or visit portal.libretranslate.com if using a hosted API key).

100% Offline Local AI

5. Local LLM via Ollama / OpenAI-Compatible Server

Run a compact multilingual LLM locally on your GPU or CPU via Ollama or LM Studio for unlimited, 100% offline chat translation with zero cloud accounts or rate limits.

Quick Start with Ollama

  1. Install Ollama from ollama.com/download.
  2. Pull a fast, lightweight multilingual model in your terminal:
ollama pull qwen2.5:3b

In TownCrier's Local LLM (Ollama / OpenAI) configuration drawer, verify the endpoint is http://localhost:11434 and the model name is qwen2.5:3b (or any installed model such as llama3.2:3b or gemma2:2b).
