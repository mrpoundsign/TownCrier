Features & Configuration Guide

Where every feature lives in TownCrier and how to configure your setup for streaming.

Live Control

1. Dashboard, Header Bar & Emergency Controls

Location: Top Header Bar • Dashboard Tab • Bottom Status Bar

The Dashboard is your real-time command center while live on stream, paired with global header and status bar controls visible from every tab:

Top Application Header

  • Platform Status Badges: Vector indicator pills for Twitch, YouTube, TikTok, and Kick illuminate as each service connects and detects an active broadcast. Hover over any badge to view connection details.
  • TTS Output Mode Selector: Quickly switch between Always On, Auto-AFK (speaks only when your keyboard/mouse has been idle), and Always Off, or press Ctrl+Shift+T from any game or window.
  • Master Volume Slider: Adjust playback gain in real time from 0% to 200% without leaving your current tab.
  • Update Indicator (⬆ Update): Appears automatically when a new GitHub Release is available. If a broadcast is currently live, TownCrier suppresses modal prompts so your stream is never interrupted.

Dashboard Speech Queue & Recent Chatters

  • Now Speaking & Queue Controls: Displays the currently speaking message, active voice ID, and pending queue depth, with 1-click buttons to Pause / Resume Queue, Skip Current, or Clear Queue.
  • Recent Spoken Messages & 文A Toggle: Shows the most recent spoken events. When foreign chat translation is active, click the 文A button in the card header to toggle between translated speech text and the chatter's original language.
  • Quick Voice Assignment: Click Assign Voice next to any chatter in the recent list to immediately customize their personal voice or playback speed.

Bottom Status Bar & Panic Mute

  • Emergency Panic Mute (Esc / Ctrl+Shift+M): Clicking the red PANIC MUTE button (or pressing Esc inside the app or Ctrl+Shift+M globally) zeroes the WASAPI audio buffer in under 50 microseconds and flushes the speech queue. Click UNMUTE (or press the hotkey again) to resume.
Core Setup

2. Application Features, Audio Output & General Settings

Location: Settings → General & Audio

All core subsystem toggles, audio output routing, default voices, and UI scaling live in the first Settings sub-tab:

Application Features Card

  • Enable Text-to-Speech (TTS): Uncheck to run TownCrier as a lightweight, chat-only aggregator and logger (<40 MB RAM, <100ms startup) without loading ONNX voice models.
  • Enable Event Logging: Toggle local SQLite chat/event recording and the Logs navigation tab.
  • Enable Foreign Chat Translation (Beta): Shows the Settings → Translation sub-tab and translates non-target-language chat messages before speaking. (See the Translation Setup Guides for provider walkthroughs.)
  • Check for TownCrier updates on startup: Queries GitHub Releases asynchronously on launch and verifies SHA-256 checksums before applying updates.

TTS Output Mode, Auto-AFK & Inactive Alert Sounds

  • Output Mode: Choose Always On, Auto-AFK (Speak When Idle), or Always Off (Muted).
  • AFK Idle Timeout: Set how long your keyboard and mouse must be untouched (15s, 30s, 1m, 2m, 5m, or 10m) before Auto-AFK activates speech. Moving the mouse or pressing a key immediately silences playback and flushes queued chat.
  • Play notification sound when TTS is inactive: Plays a built-in harmonic chime or a custom .wav / .mp3 file (with a 3-second anti-spam cooldown) whenever a qualifying message arrives while TTS is muted or while you are active at your desk in Auto-AFK mode.

Audio Output Device & Global Default Voice

  • Playback Device: Select any Windows WASAPI or Linux audio sink (such as VB-Audio Virtual Cable or Wave Link) so OBS Studio can capture TownCrier on an isolated audio track. Click Refresh Devices after plugging in headsets or virtual cables.
  • Global Default Voice & Speed: Choose the default fallback voice and speech rate (0.50x to 2.00x) used whenever a chatter or platform does not have a specific voice override. Click the speaker icon to hear a sample phrase.

Streaming Services, Known Bots & Display Scaling

  • Streaming Services Card: Check or uncheck Twitch, YouTube, TikTok, or Kick to show or hide their configuration tabs in the interface.
  • Bot Filtering Card: Toggle Ignore known stream bots (built-in list of common bots like Nightbot, StreamElements, Fossabot, Moobot, Sery_Bot, etc.) and add or remove custom bot usernames.
  • Display & Scaling Card: Lock interface DPI zoom with UI Scale (Auto (System Default), 80%, 90%, 100%, 110%, 125%, 150%, or 175%).
Portability & Recovery

3. Portable .zip Backups, Selective Import & Schema Snapshots

Location: Settings → General & Audio → Backup, Restore & Migration

TownCrier uses a unified .zip backup workflow so you can migrate across PCs, share a setup with another streamer, temporarily load someone else's backup to test or inspect their settings and restore your own afterward, or roll back across version updates:

How to Export a Backup (Export Backup…)

  1. Open Settings → General & Audio, scroll to Backup, Restore & Migration, and click Export Backup….
  2. Choose which components to include in the archive:
    • Configuration & Chatter Profiles (config-backup.json): Checked by default. Exports all chatter voice profiles, blocked words, custom bots, chat rules, platform alert templates, and Live Log tabs. OAuth tokens, WebSocket tokens, and translation API keys are automatically scrubbed.
    • Event Log & Chat History Database (events.db): Checked by default. Creates a consistent, WAL-checkpointed SQLite snapshot of your chat history and broadcast sessions.
    • Application Log (towncrier.log): Unchecked by default. Check this only if you want to include diagnostic log output for troubleshooting.
  3. Optionally type a note in the notes field (saved as support-notes.txt inside the archive) and click Create Backup (.zip)….
  4. Save the file—by default named towncrier-backup-YYYY-MM-DD-HHMMSS-v<version>.zip (for example, towncrier-backup-2026-11-08-190046-v0.0.9.zip).

How to Import a Backup or Swap Profiles (Import Backup…)

  1. Click Import Backup… and select any TownCrier .zip archive (or standalone .json config backup).
  2. Review the summary banner showing the archive version, export timestamp, chatter profile count, blocked word count, configured platforms, and whether an events.db database is included.
  3. If importing Configuration & Chatter Profiles, choose your Configuration Mode:
    • Selective Merge (Default & Recommended): Combines the selected categories (Chatter Voice & Speed Overrides, Blocked Words & Custom Bot Lists, Global Chat Rules & Platform Alert Templates, Live Log Filter Presets, and Translation Preferences) into your existing settings without wiping your current setup.
    • Full Restore: Replaces your active configuration with the backup (after automatically saving a timestamped snapshot of your current config.json so you can roll back anytime).
  4. Keep “Preserve this PC's audio output device, hardware preset & local file paths” checked when importing a backup created on another computer so your local WASAPI playback device, DirectML GPU toggle, and local alert sound paths keep working on your machine.
  5. If the .zip contains events.db, check or uncheck Restore Event Log & Chat History Database. Restoring events.db automatically backs up your current database first before swapping it in place.
  6. Click Import & Apply Backup. All tabs, voices, and Live Logs update immediately without restarting the app.

Tip — Testing Another User's Backup: Click Export Backup… to save your own .zip first, then use Import Backup… in Full Restore mode to load your friend's or partner's .zip. When you finish inspecting or testing their setup, simply import your own .zip (or restore your snapshot from Schema Snapshots…) to return to your exact setup.

Migrating Your Config & Chat History to a New PC

To move your entire TownCrier setup—including all chatter voice overrides, alert templates, blocked words, custom bots, Live Log tabs, and historical chat database—from one computer to another:

  1. On Your Old PC: Open Settings → General & Audio, click Export Backup…, leave both Configuration & Chatter Profiles (config-backup.json) and Event Log & Chat History Database (events.db) checked, and save the towncrier-backup-YYYY-MM-DD-HHMMSS-v<version>.zip file to a USB drive, network share, or cloud folder.
  2. On Your New PC (Install & Import): Install and launch TownCrier, open Settings → General & Audio, click Import Backup…, and select your .zip archive:
    • Set Configuration Mode to Full Restore (Replace settings with backup).
    • Leave “Preserve this PC's audio output device, hardware preset & local file paths” checked so TownCrier does not point at a WASAPI audio device ID or file path that only existed on your old PC.
    • Leave Restore Event Log & Chat History Database (events.db) checked so all past broadcast sessions and FTS5 search history transfer over.
    • Click Import & Apply Backup.
  3. Post-Migration Checklist on the New PC:
    • Select Your Audio Output Device: In Settings → General & Audio, pick the playback device (e.g., virtual audio cable) on the new PC.
    • Download Voice Packs Used by Your Profiles: Open Settings → TTS & Hardware and check any additional voice packs (such as Kokoro-82M or Piper LibriTTS) that your chatter profiles use so TownCrier downloads the model weights onto the new PC.
    • Reconnect Platform OAuth & API Keys: Because OAuth tokens and translation API keys are stored in each machine's local OS keyring and scrubbed from backups for security, click Connect with Twitch / YouTube (OAuth) on your platform tabs and re-enter any translation API keys in Settings → Translation.

Automatic Schema Snapshots & Downgrade Recovery (Schema Snapshots…)

  • Whenever TownCrier upgrades its configuration schema or SQLite database schema—or before you apply a Full Restore—it automatically writes a versioned backup in your data directory:
    • Config snapshots: config.YYYY-MM-DD-HHMMSS-v<schemaVersion>.json
    • Database snapshots: events.YYYY-MM-DD-HHMMSS-v<schemaVersion>.db
  • Click Schema Snapshots… at any time to view all saved configuration and database snapshots and restore any snapshot with one click.
  • Automatic Downgrade Detection: If you ever install an older version of TownCrier after running a newer release, TownCrier detects on startup that the on-disk schema version is newer than supported and offers a one-click restore of your compatible pre-upgrade snapshot.
Neural Engine

4. Neural Voice Packs, Performance Presets & Hardware Acceleration

Location: Settings → TTS & Hardware

Configure which offline neural TTS voice packs are loaded into memory and tune CPU/GPU resource consumption:

Performance Presets & Impact Meters

  • Select a one-click preset—Ultra-Low Resource (Kitten Nano), Fast & Lean (Supertonic default), Studio Quality (Kokoro-82M), Crowd Mode (Piper 904-speaker catalog), or Full Arsenal (all models)—or toggle individual voice packs manually to switch to Custom.
  • Real-time stacked impact bars display estimated Process RAM, CPU Inference Math, and DirectML GPU Acceleration for your selected combination.

Voice Model Packs & Guided Voice Replacement Wizard

  • Available Packs: Supertonic (10 voices), Kokoro-82M (34 US/UK voices, DirectML GPU support), Kokoro International (25 multilingual voices for Japanese, Mandarin, Spanish, French, Hindi, Italian, and Brazilian Portuguese), Kitten Mini (8 voices), Kitten Nano (8 voices), and Piper LibriTTS-High (904 voices).
  • Guided Replacement Voice Assignment Wizard: If you uncheck a voice pack (or select a preset that disables a pack) while any chatter profile, platform default, or stream alert is still assigned to a voice from that pack, TownCrier opens an interactive wizard listing every affected assignment so you can bulk-reassign them, preview replacement voices, or clear overrides before the pack is unloaded.

Hardware Acceleration & Idle Memory Unloading

  • Use GPU Acceleration (DirectML): Runs Kokoro FP32 (model.onnx) on any DirectX 12 compatible GPU on Windows, automatically falling back to multi-threaded INT8 CPU execution (model.int8.onnx) if unavailable.
  • CPU Threads Slider: Controls how many CPU threads ONNX Runtime uses for speech synthesis.
  • Unload Idle Models After: Automatically releases ONNX model weights from RAM after a period of chat inactivity and transparently reloads them on the next message.
Moderation & Filtering

5. Global Chat Rules, Global Hotkeys & Profanity Safety

Location: Settings → Rules & Safety

Define default chat reading rules (which all platforms inherit unless overridden), global keyboard shortcuts, and blocked word lists:

Global Chat Rules

  • Speak Chatter Names: Prepends "<Username> says:" when speaking chat messages (automatically omitted if the same chatter speaks consecutively within a short window).
  • Speak Platform Name: Includes the streaming service name (e.g., "Alice on Twitch says:") when multi-streaming.
  • Speak Emotes & Emojis: Reads emote names and Unicode emoji descriptions aloud; uncheck to strip emotes silently from speech.
  • Deduplicate Emotes: Collapses repeated emotes in a single message (e.g., Kappa Kappa Kappa is spoken once as Kappa).
  • Max Duplicate Words: Limits consecutive repeated words or copypasta spam (Allow All, Max 1 (No Repeats), Max 2, Max 3, or Max 5).
  • Ignore @Mentions & Replies: Skip chatters conversing with each other so TTS only reads messages meant for the stream:
    • Off (Speak All Messages)
    • Ignore Thread Replies Only
    • Ignore Thread Replies & Leading @Mentions
    • Ignore All @Mentions & Thread Replies
    When enabled, you can check Always speak @mentions of the broadcaster's own channel name and Play notification alert sound when a message is skipped by @mention/reply filter.

Global Hotkeys & Profanity Filter

  • Emergency Panic Mute Hotkey: Click Record Hotkey to bind any modifier + key combination (default Ctrl+Shift+M).
  • TTS Output Mode Toggle Hotkey: Cycles Always On → Auto-AFK → Always Off from anywhere (default Ctrl+Shift+T).
  • Profanity & Blocked Words: Check Block common profanity & slurs (default filter) and add custom blocked words or phrases below. Any message matching a blocked word is dropped from TTS and recorded as filtered in Event Logs.
Stream Connections

6. Platform Connections, Rule Overrides & Alert Templates

Location: Settings → Twitch • YouTube • TikTok • Kick

Each enabled streaming platform has its own dedicated Settings sub-tab:

Connecting Each Platform

  • Twitch: Enter your channel name and click Enable Twitch for instant zero-login IRC chat, or click Connect with Twitch (OAuth) to unlock full EventSub alerts (Subscriptions, Resubs, Gift Subs, Bits, Raids, Follows, Watch Streaks, Sub Upgrades, Channel Point Redemptions, Charity Donations, Announcements), Twitch AutoMod queue moderation, and inline chat moderation.
  • YouTube Live: Enter your channel @handle, channel URL, or live video URL and click Enable YouTube (no API key required for public streams). Optionally click Connect YouTube (OAuth) to enable inline chat moderation (delete/timeout/ban) and automatic detection of private or unlisted test broadcasts.
  • TikTok Live: Enter your @username and click Enable TikTok to read live chat, follows, shares, Super Fan subscriptions, and grouped gift combos.
  • Kick: Enter your Kick channel slug and click Enable Kick to read live chat, subscriptions, gifted subscriptions, reward redemptions, and live moderation events.

Granular Per-Setting Override Pulldowns

  • Every chat rule on a platform tab features an individual pulldown set to Use Global (...) by default. Switch any individual rule (such as Speak Platform Name or Ignore @Mentions & Replies) to Override: ... without affecting the rest of your global rules.
  • Optionally enable a Platform Default Voice Override so all chatters on that platform use a distinct default voice and speed.

Stream Event Alert Templates & Voices

  • Toggle individual event types (Subs, Resubs, Gift Subs, Bits / Super Chats / Gifts, Raids, Follows, Redemptions, Charity, etc.), customize the spoken template string using placeholders like {user}, {amount}, {tier}, {months}, {viewers}, {recipient}, and {message} (click the {?} button next to any template for a clickable reference of variables), and assign a dedicated voice and speed per alert type.
Chatter Profiles

7. Viewers & Chatter Voice Management

Location: Viewers Navigation Tab

Give regular chatters their own signature voice or manage per-viewer moderation overrides in the top-level Viewers tab:

  • Multi-Platform Search & Filtering: Search by username or filter by platform (All, Twitch, YouTube, TikTok, Kick).
  • Custom Voice & Speed Assignment: Select any voice from your enabled voice packs and set a custom playback speed for that specific viewer.
  • Local TTS Mute: Silence a specific chatter from TTS synthesis while leaving them unbanned in your stream chat.
  • Per-Viewer Bot Override: Override the global bot matcher per user with Default, Always Allow (Not a Bot), or Always Ignore (Treat as Bot).
Chat Feed & Database

8. Centralized Live Logs, Pop-Out Overlays & Search History

Location: Logs Navigation Tab • Settings → Event Logs

The Logs tab combines a multi-platform live chat monitor with an instant full-text historical search engine:

Live Logs & Streamlined Pop-Out Windows (Logs → Live Logs)

  • Custom Filter Tabs (+): Create multiple customized Live Log tabs (for example, All Chat, Alerts & Subs Only, or Twitch + YouTube) filtered by platform, event kind, spoken/dropped status, or current broadcast session.
  • Independent Chat Font Scaling: Adjust chat readability with 1-click zoom presets (80%, 100%, 125%, 150%) or a custom percentage slider.
  • Pop-Out Overlay Windows: Click Pop Out to open a floating, distraction-free chat window showing only the live feed and sticky stream metrics—ideal for a vertical secondary monitor or OBS Window Capture.
  • Inline Moderation & AutoMod Queue: Click moderation icons directly on any chat row to Delete, Timeout, Ban (Twitch & YouTube OAuth), Local TTS Mute, or Assign Voice, and approve/deny held messages in the Twitch AutoMod banner.

FTS5 Search History & Data Retention (Logs → Search History & Settings → Event Logs)

  • Instant Trigram Search: Search across your entire local SQLite history by keyword, username, broadcast session(s), calendar date range, platform, or event outcome.
  • Database Retention Policy: Open Settings → Event Logs to configure automatic pruning by maximum age in days or maximum row count, or run a manual prune at any time.
Hardware & Automation

9. Elgato Stream Deck Plugin & Local Control API

Location: Settings → General & Audio → Stream Deck & WebSocket Control Server

Control TownCrier from hardware macro pads, Streamer.bot, Touch Portal, or custom scripts:

  • 1-Click Elgato Stream Deck Installer: Click Install / Update Elgato Stream Deck Plugin in Settings → General & Audio to install the native plugin (com.github.mrpoundsign.towncrier.sdPlugin) with 5 actions: TTS Output Mode, Emergency Panic Mute, Speech Queue Control, Custom TTS Announcement, and Master Volume (including Stream Deck + rotary dial support).
  • Dual-Mode WebSocket & HTTP REST Server: Runs locally on 127.0.0.1:8765 by default (configurable host, port, and optional Bearer auth token), supporting binary Protocol Buffers (/ws?format=protobuf), JSON WebSocket (/ws), and REST endpoints (/api/status, /api/speak, /api/mode, /api/panic, /api/queue, /api/volume).
