Privacy Policy

Effective Date: October 24, 2026 • Last Updated: November 9, 2026

This Privacy Policy explains how TownCrier ("we", "us", or "our"), an open-source desktop software application developed by mrpoundsign and community contributors, handles data on your computer and when you choose to connect optional third-party services.

Note on Third-Party Services (As of November 9, 2026): TownCrier is an independent open-source application and is not affiliated with Google, YouTube, Twitch, TikTok, EulerStream, Kick, Translated S.r.l. (MyMemory), DeepL, LibreTranslate, Hugging Face, or GitHub. Any summaries of third-party service behavior or policies in this document are provided for convenience as of November 9, 2026. Because external providers may change their practices at any time without notice to us, we strongly encourage you to review each provider's current official Privacy Policy linked below before enabling those integrations.

1. 100% Local-Only Architecture

TownCrier does not operate any centralized servers, cloud databases, user tracking, or telemetry services.

TownCrier is a standalone desktop application for Windows and Linux. All core features—including neural text-to-speech synthesis (TTS), chat log parsing, SQLite full-text search indexing, audio playback, and profanity/bot filtering—execute entirely on your local personal computer.

We do not collect, harvest, log, transmit, or sell your personal data, chat history, stream information, credentials, or usage analytics.

2. YouTube API Services & Google User Data

TownCrier provides an optional integration with YouTube API Services to allow streamers to view live chat (including private or unlisted testing broadcasts) and perform stream moderation directly from the application.

By using TownCrier's YouTube features, you acknowledge and agree that your use is subject to the Google Privacy Policy (please review Google's current policy directly for the latest details).

Data Accessed via Google APIs

When you explicitly authenticate TownCrier with YouTube via Google OAuth 2.0 PKCE, the application requests the following scope:

  • https://www.googleapis.com/auth/youtube.force-ssl: Used exclusively to identify the authenticated broadcaster/moderator channel, read live chat on your own broadcasts when authenticated, and execute moderation commands that you initiate.

Specifically, TownCrier accesses only:

  • Channel & Broadcast Identification: Your channel ID, title, custom URL/handle, and active broadcast chat ID (via GET /youtube/v3/channels and GET /youtube/v3/liveBroadcasts) to display your active account profile and connect to your stream chat.
  • Live Chat Moderation Actions: Deleting a message (DELETE /youtube/v3/liveChat/messages) or timing out / banning a user (POST /youtube/v3/liveChat/bans) solely when you click the corresponding moderation button in TownCrier.

How Google User Data is Used

Any data received from Google APIs is processed strictly on your personal computer for the sole purpose of displaying your live chat, channel information, and carrying out moderation commands you request.

Google user data is never:

  • Transferred to external servers, cloud databases, or third parties;
  • Used for advertising, profiling, marketing, or behavioral tracking;
  • Used to train artificial intelligence or machine learning models;
  • Accessed or viewed by the TownCrier developers or any third party.

Storage & Security of Google Credentials

OAuth 2.0 access and refresh tokens returned by Google are stored solely on your local device using your operating system's native credential manager (Windows Credential Manager via the OS keyring API, or secure memory fallback on Linux). Tokens are never uploaded to any remote host and are never included in exported configuration backups.

Limited Use Disclosure

TownCrier's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking Access & Data Deletion

You have full control over your Google credentials and permissions at all times:

  • In the App: Open Settings → YouTube and click Disconnect. TownCrier immediately and permanently deletes all stored access and refresh tokens from your operating system's local credential store.
  • From Google Account Settings: You can revoke TownCrier's access at any time via the Google Security Settings Permissions page.

3. Twitch, TikTok Live & Kick Integrations

When you enable a streaming platform tab in TownCrier, your computer connects directly to that platform's endpoints. Summaries below reflect how these integrations operate as of November 9, 2026; please consult each service's official privacy policy for their current data practices:

Twitch

  • What TownCrier Sends & Receives: In anonymous IRC mode, TownCrier connects read-only to irc-ws.chat.twitch.tv using your configured channel name. If you optionally click Connect with Twitch (OAuth), TownCrier connects directly to Twitch (id.twitch.tv, eventsub.wss.twitch.tv, and api.twitch.tv/helix) to receive stream alerts (subscriptions, bits, raids, follows, channel point redemptions, charity donations, AutoMod queue) and to execute moderation actions you initiate (delete message, timeout/ban user, approve/deny AutoMod). Public emote and badge images are fetched from Twitch's CDN (static-cdn.jtvnw.net).
  • Local Credential Storage: Twitch OAuth tokens are stored exclusively in your local OS keyring and can be wiped at any time by clicking Disconnect in Settings → Twitch.
  • Official Policy: Review the Twitch Privacy Notice.

TikTok Live & EulerStream Signing

  • What TownCrier Sends & Receives: TownCrier connects to public TikTok Live rooms (tiktok.com) without requiring a TikTok account or login credentials, reading public chat, follows, shares, subscriptions, and gift events, and downloading public gift/badge icons from TikTok's CDN.
  • EulerStream WebCast Signature Service (As of November 9, 2026): After verifying that a channel is live, the open-source TikTok Live client library transmits the target channel's public room ID (and your optional EulerStream API key, if configured) to tiktok.eulerstream.com to obtain a WebCast connection signature. No personal viewer or streamer login credentials are sent by TownCrier.
  • Official Policies: Review the TikTok Privacy Policy and EulerStream Privacy Policy.

Kick

  • What TownCrier Sends & Receives: TownCrier connects directly to Kick's public channel API (kick.com) and Pusher WebSocket service (ws-us2.pusher.com) to receive public chat messages, subscriptions, gifted subscriptions, channel reward redemptions, and moderation events, and fetches public emote images from files.kick.com. Any optional Kick credentials are stored exclusively in your local OS keyring.
  • Official Policy: Review the Kick Privacy Policy.

4. Optional Foreign Chat Translation Services

Foreign chat translation (Settings → General & Audio → Enable Foreign Chat Translation) is disabled by default. When you opt in and enable translation:

  • Direct Client-to-Provider Requests: Translation requests are sent directly from your PC to the provider(s) you enable in Settings → Translation—never through any TownCrier server.
  • Data Sent for Translation: Only the foreign-language sentence text (with emote codes, URLs, and @mentions stripped where applicable) and source/target language codes are transmitted. Chatter usernames, user IDs, and stream OAuth tokens are never sent to translation providers. Messages already in your target language short-circuit locally without network traffic.
  • Local Caching & Key Storage: Translation API keys are stored in your local OS keyring (and scrubbed from exported backups). Frequently translated sentences are cached locally on your disk in cache/translations.json.

Provider-specific notes (as of November 9, 2026—please check each provider's current privacy policy directly before use):

  • MyMemory (Translated S.r.l.): Sends sentence text to api.mymemory.translated.net (and your optional email address in the de parameter if you configure the 10x free quota). As of November 9, 2026, free/anonymous MyMemory translations contribute to MyMemory's public translation memory archive. Review the MyMemory Terms and Translated S.r.l. Privacy Policy.
  • Google Cloud Translation API (Basic v2): Sends sentence text directly to translation.googleapis.com authenticated with your own Google Cloud API key. Review the Google Cloud Privacy Notice and Cloud Translation Data Usage FAQ.
  • DeepL API (Free / Pro): Sends sentence text directly to api-free.deepl.com or api.deepl.com authenticated with your own DeepL API key. Review the DeepL Pro Data Security & Privacy Policy.
  • LibreTranslate & Local LLMs (Ollama / OpenAI-Compatible): When pointed at http://localhost:5000 (LibreTranslate Docker) or http://localhost:11434 (local Ollama), translation runs 100% offline on your own machine. If you configure a remote endpoint URL, requests are governed by the operator of that endpoint.

5. Voice Model Downloads, Update Checks & Local Backups

  • Neural Voice Pack Downloads: When you download an offline TTS voice model pack in TownCrier or its setup wizard, the application downloads the model archive directly from Hugging Face (huggingface.co) or GitHub Releases (github.com). Once downloaded, all speech synthesis runs 100% offline.
  • Startup Update Checks: When Check for TownCrier updates on startup is enabled, TownCrier makes a standard HTTPS request to the public GitHub Releases API (api.github.com) to check the latest version tag and SHA-256 checksums. You can disable this check at any time in Settings → General & Audio.
  • Local Data & Portable .zip Backups: All configuration files, automatic schema snapshots, and SQLite event logs reside locally on your computer (%LOCALAPPDATA%\com.github.mrpoundsign.towncrier\ on Windows or ~/.local/share/towncrier/ on Linux). When you click Export Backup…, TownCrier creates a local .zip file at the path you choose and automatically scrubs OAuth tokens, WebSocket auth tokens, and translation API keys from config-backup.json. TownCrier never uploads backups anywhere; you control if and with whom you share a backup file.

6. Open Source Transparency

Because TownCrier is licensed under the GNU Affero General Public License v3.0, the entire application codebase is publicly auditable. You can inspect all networking, storage, and API logic directly in the TownCrier GitHub repository.
