This Privacy Policy explains how TownCrier ("we", "us", or "our"), an open-source desktop software application developed by mrpoundsign and community contributors, handles data.

1. 100% Local-Only Architecture

TownCrier does not operate any centralized servers, cloud databases, user tracking, or telemetry services.

TownCrier is a standalone desktop application for Windows and Linux. All core features—including text-to-speech synthesis (TTS), chat log parsing, SQLite search indexing, sound playback, and filtering—execute entirely on your local personal computer.

We do not collect, harvest, log, or sell your personal data, chat history, stream information, or usage analytics.

2. YouTube API Services & Google User Data

TownCrier provides an optional integration with YouTube API Services to allow streamers to view live chat and perform stream moderation directly from the application.

By using TownCrier's YouTube features, you acknowledge and agree that your use is subject to the Google Privacy Policy.

Data Accessed via Google APIs

When you explicitly authenticate TownCrier with YouTube via Google OAuth 2.0 PKCE, the application requests the following scope:

  • https://www.googleapis.com/auth/youtube.force-ssl: Used exclusively to identify the authenticated broadcaster/moderator channel and to execute moderation commands that you initiate.

Specifically, TownCrier accesses only:

  • Channel Identification: Your channel ID, title, and public custom URL / handle (via GET /youtube/v3/channels?part=snippet&mine=true) to display your active account profile in the Settings window.
  • Live Chat Moderation Actions: Deleting a message (DELETE /youtube/v3/liveChat/messages) or timing out / banning a user (POST /youtube/v3/liveChat/bans) solely when you click the corresponding moderation button in TownCrier.

How Google User Data is Used

Any data received from Google APIs is processed strictly in real-time memory on your personal computer for the sole purpose of displaying channel information and carrying out moderation commands you request.

Google user data is never:

  • Transferred to external servers, cloud databases, or third parties;
  • Used for advertising, profiling, marketing, or behavioral tracking;
  • Used to train artificial intelligence or machine learning models;
  • Accessed or viewed by the TownCrier developers or any third party.

Storage & Security of Google Credentials

OAuth 2.0 access and refresh tokens returned by Google are stored solely on your local device. TownCrier stores credentials using your operating system's native secure credential manager (Windows Credential Manager via the OS keyring API, or secure memory fallback on Linux). Tokens are never uploaded to any remote host.

Limited Use Disclosure

TownCrier's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking Access & Data Deletion

You have full control over your Google credentials and permissions at all times:

  • In the App: Open Settings → YouTube and click Disconnect. TownCrier immediately and permanently deletes all stored access and refresh tokens from your operating system's local credential store.
  • From Google Account Settings: You can revoke TownCrier's access at any time via the Google Security Settings Permissions page.

3. Other Platform Integrations (Twitch, Kick, TikTok)

TownCrier connects directly from your local machine to third-party streaming platform APIs and chat sockets (Twitch IRC/Helix, Kick API/WebSockets, TikTok Live WebSockets):

  • Any platform credentials (such as Twitch OAuth tokens) are stored exclusively in your local operating system keyring.
  • Chat logs, event records, and search indexes are stored locally in an embedded SQLite database on your device (%LOCALAPPDATA%\com.github.mrpoundsign.towncrier\ on Windows or ~/.local/share/towncrier/ on Linux).
  • No platform data is ever mirrored or forwarded to external servers.

4. Open Source Transparency

Because TownCrier is licensed under the GNU Affero General Public License v3.0, the entire application codebase is publicly auditable. You can inspect all networking, storage, and API logic directly in the TownCrier GitHub repository.

5. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in functionality or applicable regulations. Any updates will be posted to this page with an updated "Last Updated" date.
