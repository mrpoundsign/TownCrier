Local Control API & WebSocket Reference

Trigger custom TTS messages, control the speech queue, subscribe to live speech events, and drive OBS overlays from Streamer.bot, Touch Portal, scripts, or hardware controllers.

Quick Start

1. Overview & Enabling the Server

Location: Settings → General & Audio → OBS Overlays & External Control

TownCrier embeds a local HTTP REST, dual-mode WebSocket (JSON + binary Protocol Buffers), and Server-Sent Events (SSE) server that runs in-process at http://127.0.0.1:8765 (ws://127.0.0.1:8765/ws) by default.

Server Feature Toggles

The listener starts automatically whenever at least one of the three independent toggles in OBS Overlays & External Control is checked:

  • Enable External Control API & Elgato Stream Deck (/ws, /api/*): Unlocks all HTTP control endpoints (/api/status, /api/speak, /api/mode, /api/panic, /api/queue, /api/volume) and mutating commands over WebSocket.
  • Enable OBS 'Now Speaking' Caption Overlay (/overlay/tts): Requires Enable Text-to-Speech (TTS). Enables /overlay/tts, /overlay/designer, /api/overlay/style, and read-only WebSocket connections on /ws (mutating commands are rejected with HTTP/WS error "external control api is disabled in TownCrier settings" unless the Control API toggle is also enabled).
  • Enable OBS Live Chat & Alerts Overlay (/overlay/chat): Requires Enable Event Logging. Enables /overlay/chat, /api/overlay/chat, /api/overlay/stream, and the Overlay Designer.

To change the bind address, port, or shared secret, edit Host, Port, or Auth Token and click Apply Network Settings.

Protocol & Security

2. Authentication, CORS & Wire Formats

Authentication

When Auth Token is left blank in Settings, all endpoints accept unauthenticated local requests. Once an Auth Token is configured, every HTTP, WebSocket, and overlay route requires it via either:

  • HTTP Header: Authorization: Bearer <token> (or raw Authorization: <token>)
  • Query Parameter: ?token=<token> (useful for OBS Browser Source URLs, browser WebSocket clients, and simple webhook callers)

Tokens are validated using constant-time comparison.

Network Binding Security Warning: Keep Host set to 127.0.0.1 unless you need to reach TownCrier from another PC (such as a dual-PC streaming setup). Always configure a strong Auth Token before changing Host to a LAN IP or 0.0.0.0, and limit network access with your local firewall.

CORS & Preflight Handling

  • Every response sets Access-Control-Allow-Origin: *, Access-Control-Allow-Methods: GET, POST, OPTIONS, and Access-Control-Allow-Headers: Authorization, Content-Type.
  • HTTP OPTIONS preflight requests return 204 No Content immediately without requiring an Auth Token.

JSON vs. Binary Protocol Buffers Negotiation

  • Default Format (application/json): All /api/* responses default to JSON encoded with protojson (EmitUnpopulated: true). Field names in responses use lowerCamelCase (for example queueDepth, outputMode, speechEvent), and 64-bit integer idleSeconds serializes as a JSON string (e.g. "0").
  • Binary Protobuf (application/x-protobuf): Pass Content-Type: application/x-protobuf and/or Accept: application/x-protobuf on HTTP calls to send and receive raw serialized towncrier.control.v1 messages.
  • Request Body Limits: /api/speak reads up to 64 KiB; all other control POST endpoints read up to 16 KiB.

Speech Queue API

3. Sending Custom Messages (POST /api/speak)

Enqueue arbitrary text directly into TownCrier's priority speech queue from channel point redemptions, stream alerts, timers, bots, or scripts. You may send JSON (snake_case or camelCase keys accepted), binary SpeakCommand Protobuf, or a ?text= query parameter fallback on an empty POST body.

Request parameters for POST /api/speak and WebSocket speak commands
Field Type Default Description
text string Required Text to synthesize and speak. Trimmed; returns 400 if empty. Can also be passed via query string ?text=... when body text is blank.
voice_id string Global Default Voice Canonical TownCrier voice ID (e.g., supertonic:f1, supertonic:m2, af_bella, piper:spk_0). If omitted or blank, uses GlobalChatRules.DefaultVoice.
speed float32 Global Default Speed (1.0) Speech rate multiplier. Any value <= 0 falls back to your configured global default speed (or 1.0).
priority int32 0 (High / Events) 0 places the message in the Events tier (spoken ahead of regular chat with no staleness expiry). Any non-zero value (e.g. 1) places it in the Chat tier (subject to the 30-second burst staleness TTL).
username string "RemoteControl" Display label shown in the SpeechEvent payload and the OBS Now-Speaking overlay.

Queue & Pipeline Behavior: Custom messages are enqueued directly with platform: "websocket", bypassing chat profanity/emote filters, per-viewer voice routing, and TTSOutputMode (Auto-AFK / Always Off) gating so alerts and Stream Deck announcements still play when chat TTS is paused by mode. They require Enable Text-to-Speech (TTS) to be enabled (otherwise 400 "TTS is disabled"), are dropped while Emergency Panic Mute is active, reset consecutive-speaker name suppression, and trigger SpeechEvent broadcasts on /ws and /overlay/tts—but are not written to the Live Log feed, SQLite history, or /overlay/chat.

HTTP REST

4. Control REST Endpoints

All control REST endpoints return a ServerEnvelope containing the updated StateSnapshot and broadcast state updates to connected /ws clients whenever a command mutates state.

GET /api/status

Returns 200 OK with the current StateSnapshot (read-only).

POST /api/mode

Sets or cycles the TTS output mode. Accepts JSON {"mode": "...", "idle_timeout_seconds": 30} or query parameter ?mode=...:

  • mode values (case-insensitive): "always_on", "auto_idle" (aliases: "auto", "idle", "afk"), "always_off" (aliases: "off", "disabled", "muted"), or "cycle" / "toggle" (advances Always On → Auto-AFK → Always Off → Always On). Unknown or empty values default to always_on.
  • idle_timeout_seconds (optional positive integer): Updates the Auto-AFK inactivity threshold in seconds.

POST /api/panic

Controls Emergency Panic Mute. Accepts JSON {"action": "..."} or ?action=...: "toggle" (default if omitted), "mute" (aliases: "on", "panic"), or "clear" (aliases: "unmute", "off", "reset").

POST /api/queue

Controls speech queue playback. Accepts JSON {"action": "..."} or ?action=... with one of four actions (missing or unrecognized values return 400 Bad Request):

  • "pause" — Pauses queue dispatch and immediately halts active audio playback mid-speech.
  • "resume" — Unpauses the queue, clears Panic Mute if active, and resumes active speech cleanly from the start of the interrupted sentence.
  • "skip" — Aborts the currently speaking item and advances to the next queued item.
  • "clear" — Flushes all pending items and stops the currently speaking item.

POST /api/volume

Updates and persists master TTS playback volume. Accepts JSON with "volume" (absolute level) and/or "delta" (relative offset applied after volume if both are provided). At least one field must be present (otherwise returns 400 Bad Request); the resulting level is clamped to 0.0–1.0.

GET /api/actions

Returns JSON listing all enabled Bot Automation actions (bot_actions) and running v1.1.0 plugin actions (plugin_actions, including controller types and dynamic live tile visuals) for PoundControl, Stream Deck, or scripts.

Real-Time Bidirectional

5. Dual-Mode WebSocket API (/ws)

Connect to ws://127.0.0.1:8765/ws (with optional ?token=YOUR_TOKEN or Bearer header) for low-latency commands and real-time broadcasts.

  • Text JSON vs. Binary Protobuf: Connects in JSON text mode by default. Pass ?format=protobuf (aliases: proto, bin, binary) or include protobuf in the Sec-WebSocket-Protocol header to default to binary Protobuf frames. Each incoming frame also switches that client's active mode dynamically (text frames return JSON; binary frames return binary Protobuf).
  • Initial Snapshot & Live Push: Immediately upon connecting, the server sends a ServerEnvelope containing the current state (StateSnapshot). Whenever state changes or speech items start/finish, the server pushes updated StateSnapshot and SpeechEvent envelopes to connected clients.
  • Read-Only Overlay Mode: If Enable OBS 'Now Speaking' Caption Overlay is on while Enable External Control API is off, /ws allows connections and get_state queries, but rejects all mutating commands.

Flat Convenience JSON vs. Canonical protojson

Over JSON WebSocket frames, TownCrier accepts both canonical protojson ClientEnvelope objects (such as {"requestId":"1","speak":{"text":"Hi"}}) and flat convenience objects using "action" (or "command") with snake_case keys:

Supported flat JSON convenience actions on ws://127.0.0.1:8765/ws
Action / Aliases Parameters Effect
get_state, state, status None (optional request_id) Returns current StateSnapshot (read-only; allowed when Control API is disabled)
cycle_tts_mode, cycle_mode, toggle_mode None Cycles output mode: Always On → Auto-AFK → Always Off
set_tts_mode, set_mode, mode mode, optional idle_timeout_seconds Sets output mode (always_on, auto_idle, always_off) and optional AFK timeout
speak, tts text, optional voice_id, speed, priority, username Enqueues a custom TTS announcement directly into the speech queue

8. Plugin ABI v1.1.0 & Overlay Widgets

TownCrier’s proto/plugin/v1 host protocol is at Host API v1.1.0 (HOST_API_MAJOR = 1, HOST_API_MINOR = 1, HOST_API_PATCH = 0), remaining backwards-compatible with all v1.0.x WASM and Native Subprocess plugins. Both backends support the same manifest, lifecycle, bot automation, and overlay capabilities.

Supported Capabilities

Declare required and optional feature strings in your plugin Manifest:

core.v1        events.v1        kv.v1             http.v1
tts.v1         overlay.v1       ui.v1             overlay.routes.v1
overlay.widgets.v1
bot.events.v1  bot.before_tts.v1  bot.chat.v1     bot.moderate.v1
bot.variables.v1  bot.actions.v1

OverlayWidgetDescriptor (overlay.widgets.v1)

Adding entries to Manifest.overlay_widgets (field 18) registers plugin-supplied browser widgets directly on the Unified OBS Canvas (/overlay) and in the Tabbed Style Designer (/overlay/designer). Plugins must also enable permissions.overlay_broadcast or declare overlay.widgets.v1 / overlay.routes.v1.

Field Type Notes & Constraints
id string Required; unique per plugin, matches [A-Za-z0-9_-]+, max 64 characters
name / description string Human-readable widget title and tooltip shown in the Style Designer
entry_asset string Relative asset path inside the plugin overlay bundle (defaults to index.html)
default_x, default_y, default_w, default_h double Default canvas placement and size; pair with optional min_w / min_h
default_hidden bool When true, widget starts hidden on /overlay until enabled by the user
supports_host_theme bool Allows users to inherit TownCrier’s --tc-* CSS theme variables
style_schema repeated SettingField Declarative style controls rendered automatically inside /overlay/designer
disable_custom_css bool Hides the per-widget custom CSS editor in the Style Designer

Go SDK & Host Theme CSS Variables

  • Optional Go Interface (pkg/pluginsdk): Implement OverlayAssetPlugin (GetOverlayAsset(assetPath string)) to serve HTML/CSS/JS/image assets, and optionally OverlayStylePlugin (OnOverlayStyleChanged(req *pluginv1.OnOverlayStyleChangedRequest)) to react live when the user updates widget_id, values (SettingsMap), custom_css, or use_host_theme in /overlay/designer.
  • Host Theme CSS Custom Properties: When use_host_theme is active, /overlay/assets/sdk.js sets data-tc-host-theme="1" on <html> and injects: --tc-bg, --tc-bg-solid, --tc-bg-opacity, --tc-border, --tc-accent, --tc-text, --tc-muted, --tc-radius, --tc-font-scale. It also applies .tc-embedded when loaded inside /overlay (?embedded=1) and .tc-preview in Style Designer previews (?preview=1).

Widget Browser SDK Example (/overlay/assets/sdk.js)

<script src="/overlay/assets/sdk.js"></script>
<script>
  const conn = window.TownCrierOverlay.connect({
    widgetId: "now-playing", // or pass pluginUUID explicitly
    events: ["track", "progress"],
    onStyle(stylePayload) {
      // stylePayload: { widget_id, use_host_theme, values, custom_css, host_theme }
      console.log("Updated widget style:", stylePayload.values);
    },

      if (eventName === "track") renderTrack(data);
    },
  });
</script>

PoundControl (Curated WebAssembly Plugin)

Integrate TownCrier directly into PoundControl desktop and mobile/Wear OS touch decks in under a minute:

  1. In PoundControl, open Settings → Plugins → Curated Catalog and click Install next to TownCrier & Plugins (com.github.mrpoundsign.towncrier.wasm).
  2. Open Settings → TownCrier inside PoundControl, confirm Host (127.0.0.1) and Port (8765), paste your Auth Token if configured, and click Save.
  3. Ensure Enable External Control API is checked in TownCrier's Settings → OBS & Overlays tab. PoundControl automatically polls /api/actions at startup and exposes dynamic tiles for both Bot Automation workflows and running native plugins (such as CrowdDJ).

Touch Portal, SAMMI & Mix It Up Webhooks

Any automation tool capable of making local HTTP requests or opening a WebSocket can control TownCrier directly:

  • Endpoint URL: http://127.0.0.1:8765/api/speak (or /api/queue, /api/panic, /api/mode, /api/volume)
  • HTTP Method: POST
  • Headers: Content-Type: application/json and (if an Auth Token is set) Authorization: Bearer YOUR_TOKEN
  • WebSocket Alternative: Connect your automation tool's custom WebSocket client to ws://127.0.0.1:8765/ws?token=YOUR_TOKEN and send flat JSON frames such as {"action":"skip"} or {"action":"speak","text":"..."}.
